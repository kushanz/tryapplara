- Follow the architecture and backend rules defined in `laravel-api-backend-docs`
- Keep master instructions and guard rails in one place
- Track development progress continuously
- Record user stories whenever new features or flows are introduced

## Working Agreement For Future Development

1. Read `master-instruction.md` before starting a task.
2. Follow the architecture docs before making implementation decisions.
3. Add any newly discovered feature flow or requirement to `user-stories.md`.
4. Update `progress-tracker.md` whenever a task is completed, changed, or newly planned.
5. Keep this folder as the source of truth for project-level progress and rules.

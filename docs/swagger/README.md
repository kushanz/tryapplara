# Swagger Documentation

This folder contains OpenAPI/Swagger documents for the Laravel API.

## Available Specs

- Authentication: [`auth.openapi.json`](./auth.openapi.json)

## Usage

- Import `auth.openapi.json` into Postman, Swagger Editor, or any OpenAPI-compatible tool
- Keep this spec updated whenever auth request or response shapes change
- Add new module-specific OpenAPI files here as the project grows
